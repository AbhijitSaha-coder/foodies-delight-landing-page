# Foodie’s Delight – Restaurant Landing Page

A simple and elegant landing page for the restaurant **Foodie’s Delight**, built using **HTML** and **CSS**.  
The page showcases the restaurant’s brand, popular dishes, and a contact form for customer inquiries.

---

## 🎯 Project Overview
This landing page is designed to give visitors a brief introduction to **Foodie’s Delight**.  
It features:
- A main heading with the restaurant name
- A short descriptive paragraph about the restaurant
- Two food images displayed side by side with captions
- A link to view the full menu
- A contact form to collect name, email, and message

The project demonstrates basic webpage structure, layout, and styling using HTML and CSS.

---

## 🧱 Technologies Used
- **HTML5** — For page structure and content  
- **CSS3** — For styling, layout, and visual appeal  

---

## ⚙️ Features
- Soft background color and centered text  
- Side-by-side images with borders and captions  
- “View Full Menu” link with hover effect  
- Contact form with name, email, and message fields  
- Form styled with fixed width, padding, border, and rounded corners  
- Heading with a different font and color
